# Résumé du cours : L'Intelligence Artificielle et l'IA Générative

## 1. Hiérarchie des concepts (Du général au spécifique)
-IA (Intelligence Artificielle) : Le domaine général qui englobe toutes les technologies visant à imiter l'intelligence humaine.
-ML (Machine Learning) : Sous-ensemble de l'IA axé sur l'apprentissage automatique à partir de données.
  -Applications : Classification et Prédiction.
-DL (Deep Learning) :Sous-ensemble du Machine Learning utilisant des réseaux de neurones artificiels (Réseaux Neurones).
-LLM (Large Language Models) : Sous-ensemble du Deep Learning spécialisé dans le traitement et la création de contenu.
 Rôle : Création de contenu (Texte, Vidéo, Audio, etc.).

---

## 2. Limites de l'Intelligence Artificielle
1. Hallucinations : L'IA peut générer des réponses fausses ou générer des informations de manière très convaincante mais incorrectes.
2. Biais (Biases) : Présence de préjugés ou de distorsions basés sur les données d'entraînement.

---

## 3. Notions clés
-Nuance IA vs IA Générative :** L'IA traditionnelle analyse, classifie ou prédit, tandis que l'IA Générative (comme les LLM) crée du nouveau contenu.
